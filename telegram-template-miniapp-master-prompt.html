Deep research / product implementation

Мастер‑промпт для магазина Telegram‑ботов

Готовое задание для AI‑кодера или команды: Mini App, каталог, deep links из канала, Telegram Stars, защищённая выдача файлов, лицензии, админка и аналитика.

Основная версия: telegram-template-miniapp-master-prompt.md
01 / STRATEGY

Начать с single‑vendor

Сначала продаются собственные решения. Multi‑vendor, escrow, криптооплата и сложные подписки откладываются до подтверждения спроса.

02 / CONVERSION

Пост → конкретный товар

Канал не дублирует каталог. Он показывает короткий результат и ведёт через ?startapp=product_[id] прямо в карточку товара.

03 / TRUST

Продаётся запуск, не ZIP

У каждого шаблона есть demo, список функций, требования, лицензия, версия, changelog и понятный путь после оплаты.

Ключевой пользовательский путь

КаналКороткая карточка с обещанием результата.
Deep linkОткрывает нужный товар, а не общий бот.
DemoФункции, лицензия, стек, цена в Stars.
ДоступInvoice → подтверждение → защищённая выдача.

Что уже заложено в полном промпте

  • Mobile-first UX для ширины 360–430 px.
  • Светлая и тёмная тема через Telegram theme params.
  • BackButton, BottomButton, safe area и loader.
  • Каталог, поиск, категории по бизнес-задачам.
  • Карточка товара, лицензии, отзывы после покупки.
  • «Мои покупки», версии, changelog, повторный доступ.
  • Stars `XTR` для цифровых товаров.
  • Платёжный lifecycle до `successful_payment`.
  • Идемпотентность webhook и хранение charge id.
  • Валидация `initData` только на сервере.
  • Signed URLs, RBAC, rate limits, XSS/SSRF checks.
  • Тесты, seed, README, BotFather и deploy checklist.
Главное решение

Не копировать визуальный стиль WorkHub. Взять его воронку и сделать собственный «developer marketplace / launchpad»: графитовая база, мятный акцент, сильные превью и спокойная типографика. Внутри Telegram для цифровых шаблонов использовать Stars, а не Stripe или криптовалюту.
