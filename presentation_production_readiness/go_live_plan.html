10 / GO-LIVE

План выхода в production

Railway deployment считается подтверждённым только после прохождения всей цепочки — от credentials до Telegram smoke tests.

01

ОТКРЫТЬ GATE

Авторизовать Railway CLI или обновить GitHub environment secrets и repository variables: token, project, environment, service и staging URL.

PRECONDITION: no secret in logs
02

DEPLOY + DATA

Запустить Docker deploy, затем применить immutable migrations и проверить schema status на staging PostgreSQL.

CHECK: /health/ready
03

SMOKE FLOWS

Проверить HTTPS health/metrics, Telegram webhook, Mini App deep link, Stars payment, entitlement, duplicate update и refund flow.

EVIDENCE: request IDs only
04

SEPARATE PROD

После staging sign-off создать отдельные production bot, database, Redis namespace и private S3/R2 bucket.

GO: staging verified
NO-GO RULEНе переводить проект в production, пока ручной Railway run не завершится успешно и не подтверждены migrations, schema, health endpoints и Telegram critical paths.
