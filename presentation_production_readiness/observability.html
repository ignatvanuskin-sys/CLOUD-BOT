03 / OBSERVABILITY

Production-архитектура стала наблюдаемой

01

REQUEST

Каждый запрос получает request ID для корреляции событий между слоями.

02

TELEMETRY

OpenTelemetry собирает traces и metrics и экспортирует их через OTLP.

03

HEALTH

/health/live, /health/ready и защищённые metrics дают явные сигналы состояния.

04

GATE

Railway healthcheck использует readiness endpoint до подачи трафика.

Система сигнализирует не только о сбое, но и о его контексте.
Логи: структурированные события без токенов и секретов.
Сервис: отдельный OTEL service name для окружения.
Deploy: Docker manifest задаёт healthcheck timeout и restart policy.
