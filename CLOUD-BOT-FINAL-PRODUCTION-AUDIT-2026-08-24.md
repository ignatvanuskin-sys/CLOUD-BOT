# Bugs Found

## BUG-001 — Main-content mouse wheel blocked

- Severity: P0
- Root cause: `body` combined `overflow-x: hidden` and `overscroll-behavior: none`, creating an inert overflow context and preventing wheel chaining to the viewport.
- Evidence: Playwright native `mouse.wheel` over content produced no `scrollY` movement before the fix; after the fix it moved approximately 400px. Wheel events were delivered and not cancelled.
- Fix: move overscroll suppression to `html`; make `#root` overflow visible and separate it from horizontal containment.
- Status: PASS locally.

## BUG-002 — Potential blank shell during route transition

- Severity: P0
- Root cause: blocking `AnimatePresence mode="wait"` could leave the route shell empty if an exit animation was interrupted in a WebView.
- Evidence: current route rendered correctly, but the transition sequencing had a real blank-state risk.
- Fix: replace blocking `AnimatePresence` transition with non-blocking keyed `motion.div`.
- Status: PASS locally and in production bundle smoke tests.

## BUG-003 — E2E environment was not isolated

- Severity: P1
- Root cause: Playwright used occupied ports and shared/unstable test runtime state.
- Fix: dedicated ports 5174/8788, isolated DB/storage paths, and a reusable config retained for occupied-server workflows.
- Status: PASS: full E2E suite 9/9.
